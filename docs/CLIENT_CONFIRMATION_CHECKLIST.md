# Что нужно подтвердить у клиента перед публикацией

Пункты ниже влияют на данные сайта. Спорные позиции **не опубликованы**
автоматически: в базе они помечены `needsConfirmation=true` и скрыты из витрины
(`isHidden=true`). Их видно в админке (Меню → фильтр «требуют подтверждения») с
предупреждением. После подтверждения снимите оба флага, чтобы опубликовать.

## 1. Спорные цены

- [ ] **Шашлык из вырезки телятины** — предположительно **220 ₽ / 100 г**. Подтвердить.
- [ ] **Шашлык из баранины, каре** — предположительно **250 ₽ / 100 г**. Подтвердить.

## 2. Спорные веса / тип продажи

- [ ] **Скумбрия, цельная** — цена 150 ₽. Уточнить: за 100 г или за целую рыбу?
      Сейчас смоделирована как штучная (UNIT). Подтвердить тип и вес.
- [ ] **Перепела** — 200 ₽. Уточнить: продажа поштучно или за порцию/вес?
      Сейчас — штучно (UNIT). Подтвердить.

## 3. Составы

- [ ] **Шаурма с сыром и сулугуни** — уточнить точный состав (сейчас «уточняется»).
- [ ] **Шаурма по-арабски** — предварительно: курица, салат, огурцы, картофель фри,
      лаваш. Подтвердить/уточнить.
- [ ] **Хачапури с куриным мясом** (700 ₽, 550 г) — подтвердить **название и состав**
      (позиция скрыта до подтверждения).
- [ ] **Хачапури со свино-говяжьим мясом** (700 ₽, 550 г) — подтвердить **название и
      состав** (позиция скрыта до подтверждения).

## 4. Правило минимального заказа

- [ ] Подтвердить, что минимум считается **по весу — 300 г** (а не по сумме).
      Сейчас реализовано по весу. Значение редактируется: Настройки → Доставка.

## 5. Фотографии блюд

- [ ] Предоставить настоящие фото блюд. Загрузка — Меню → товар → блок «Фото»
      (JPEG/PNG/WebP/AVIF, до 5 МБ). До загрузки показываются нейтральные заглушки.

## 6. График работы

- [ ] Указать часы работы (Настройки → «Часы работы»). Сейчас **пусто** — ложное
      расписание не показывается, отображается «Принимаем заказы онлайн».

## 7. Зоны и стоимость доставки

- [ ] Подтвердить границы бесплатной зоны и стоимость доставки при сумме < 1500 ₽.
      Сейчас для таких заказов стоимость помечается «уточнит оператор».
- [ ] Бесплатный порог (1500 ₽) — редактируется: Настройки → Доставка.

## 8. Реквизиты владельца

- [ ] Предоставить реквизиты (ИП/ООО, ИНН) для футера и документов.
      Поле: Настройки → «Реквизиты владельца».

## 9. Способ оплаты / эквайринг

- [ ] Подтвердить доступные способы оплаты.
- [ ] Для онлайн-оплаты: выбрать эквайринг, предоставить merchant credentials,
      webhook URL; провести тесты (платёж, возврат, повторный webhook). До этого
      онлайн-оплата на витрине выключена.

## 10. Карта (2ГИС)

- [ ] Предоставить ссылку на встраиваемую карту 2ГИС и/или карточку организации.
      Поля: Настройки → «URL встраиваемой карты», «URL маршрута».

## 11. Социальные сети

- [ ] Предоставить ссылки на соцсети (появятся в футере).
      Настройки → «Соцсети» (по строке «Название|ссылка»).

## 12. Тексты юридических документов

- [ ] Согласовать/заменить черновики: Политика конфиденциальности, Согласие на
      обработку данных, Условия заказа (`/legal/*`). Сейчас — черновики с пометкой.

## 13. Реальные отзывы

- [ ] Блок отзывов **выключен** по умолчанию (фейковые отзывы не создаём).
      Включить и наполнить реальными отзывами: Настройки → «Показывать блок отзывов».

## 14. Смена пароля администратора

- [ ] Сменить пароль администратора по умолчанию:
      `npm run admin:create -- <логин> <новый-пароль>`.
- [ ] Задать надёжный `AUTH_SECRET` в production `.env`.
