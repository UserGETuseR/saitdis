# Язык интерфейса

## Голос VetSvet

Спокойный, ясный, уважительный и живой. Не сюсюкает, не пугает, не прячется за канцеляритом и не говорит от лица врача то, чего врач не подтвердил.

## Микрокопия по ситуации

| Ситуация | Вместо | VetSvet говорит |
| --- | --- | --- |
| Начать запись | «Оформить заявку» | «Выбрать заботу для питомца» |
| Срочный маршрут | «Экстренная услуга» | «Нужна помощь сейчас» |
| Сохранение формы | «Обработка данных» | «Сохраняем — можно продолжить позже» |
| Ожидание специалиста | «Заявка принята» | «Запрос у команды. Сообщим, когда специалист возьмёт его в работу» |
| Деньги | «Оплатить» без контекста | «Оплатить консультацию — 1 500 ₽» |
| Ошибка | «Ошибка 500» | «Не получилось отправить. Данные остались здесь — попробуйте ещё раз» |

## Правила

- В кнопке — конкретное действие, а не абстрактное «Продолжить».
- Цена, результат, срок и возможность отмены объясняются до необратимого шага.
- Владелец не получает медицинский жаргон без пояснения; сотрудник не видит «детский» UI.
- Не называть animal owner «клиентом» там, где речь о его питомце; для команды термин допустим в операционных экранах.
- Копирайтинг — гипотеза, которую проверяем тестами, а не «факт о психологии».
