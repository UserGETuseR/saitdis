# Service blueprints

## Груминг: первая эталонная цепочка

| Дорожка | События |
| --- | --- |
| Владелец | выбирает цель → видит понятную цену/длительность → выбирает слот → вносит депозит → получает напоминание → привозит питомца → получает статус/отчёт → повторяет удачный уход |
| Видит в системе | карточка услуги, удобная доступность, условия, статус, фото до/после, результат, следующий шаг |
| Команда | проверяет профиль/рецепт → check-in → проводит услугу → фиксирует расход/заметки → публикует report → оформляет расчёт |
| Автоматизация | резервирует ресурсы, отправляет согласованные напоминания, создаёт timeline, отслеживает неоплаченный счёт, предлагает rebook без давления |
| Внешнее | платёжный/fiscal provider, файловое хранилище, выбранный канал уведомлений |

Разрывы между этими дорожками считаются продуктовым дефектом, даже если сам экран выглядит хорошо.
