# Доступность: обязательный уровень

Цель — WCAG 2.2 AA для публичной и клиентской части, с ещё более строгой ясностью в staff/clinical сценариях.

- Полная клавиатурная навигация, логичный focus и skip links.
- Контраст, масштабирование текста, понятные label/error-summary и связь ошибки с полем.
- Не полагаться только на цвет, звук, hover или drag-and-drop.
- Touch targets не меньше комфортного мобильного размера; форма не теряет введённое при ошибке сети.
- `prefers-reduced-motion` отключает декоративные анимации без потери смысла.
- Фото имеют осмысленные alt там, где несут информацию; декоративные — скрыты от скринридера.
- В urgent flow не использовать autoplay, тяжёлые фоны или сложные прокрутки.
