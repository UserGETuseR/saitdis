# Public Web — визуальная первая поверхность

`index.html` — автономный рабочий визуальный прототип публичного VetSvet. Он использует реальные изображения из `../../Photo`, не зависит от текущего магазина и специально не содержит выдуманных реквизитов, цен, врачей или подключённых сервисов.

Следующий шаг — перенести эту поверхность в отдельное SSR/Next.js приложение после создания workspace и подключить подтверждённые контентные данные/маршруты записи. Визуальные решения, анимации и поведение на мобильном уже можно проверять и улучшать отдельно от бэкенда.
