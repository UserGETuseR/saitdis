# «Мне можно» — сайт студии наращивания волос

Статический одностраничный сайт студии наращивания волос «Мне можно» (мастер Ольга, Москва).
Тёмный премиальный дизайн 2026 в rose-gold / champagne / violet палитре, со **сквозным
горизонтальным скроллом**: страница едет **вбок**, а не вниз. Вверху — **фоновое видео**,
фото «выплывают» из-за блоков и соединяются в коллаж, заголовки собираются по буквам,
отзывы — отдельная горизонтальная лента.

## 🚀 Как запустить

Сайт полностью статический и работает прямо с диска (`file://`), **без сборки и без сервера**.

- **Двойной клик по `START.bat`** — откроется `index.html` в браузере по умолчанию.
- Либо просто откройте `index.html` двойным кликом.

## 🎬 Видео в шапке (hero)

Вверху страницы — фоновое видео. Чтобы оно появилось:

1. Положите файл в папку **`mne-mojno-site/video/`** с именем **`hero.mp4`**
   (можно дополнительно `hero.webm` — он меньше и быстрее в современных браузерах).
2. Обновите страницу — видео заведётся само (muted, loop, autoplay).

```
mne-mojno-site/
└── video/
    ├── hero.mp4    ← основной файл (обязательно)
    └── hero.webm   ← опционально
```

**Если видео нет или не загрузилось** — ничего не сломается: hero автоматически покажет
фото-фон (одно из фото `ФОТООЛЯ`) и весь текст останется читаемым. Это сделано через
обработчик `error` на `<video>` (класс `no-video`) и фото-подложку в CSS.

### Где взять бесплатное видео с лицензией для коммерческого использования

- **Pexels Video** — https://www.pexels.com/videos/
- **Mixkit** — https://mixkit.co/free-stock-video/
- **Coverr** — https://coverr.co/

Эти площадки разрешают бесплатное коммерческое использование (всё равно проверяйте
конкретную лицензию у выбранного ролика).

> ⚠️ **Не используйте** ролики, скачанные с **Pinterest / Klickpin** и подобных ре-аплоадов —
> они **не лицензированы** для коммерческого использования и могут нарушать авторские права.

Рекомендации: короткий (8–20с) бесшовный луп, muted, H.264/MP4, желательно до ~10–15 МБ.

## 🧭 Как устроен горизонтальный скролл

- Все секции — это **панели** шириной ~100vw в общем треке `#horizontal-track`.
- На десктопе панели **пинятся** и переводятся по X с помощью GSAP **ScrollTrigger**
  (вертикальное колесо мыши → горизонтальное движение сайта). Сверху — тонкий
  **прогресс-бар**, у hero — подсказка «Листайте — сайт едет вбок →», исчезающая после
  первого скролла.
- **Порядок панелей:** Hero (видео) → О студии/Ольга → Услуги → Работы (галерея) →
  Цифры → Отзывы (лента) → Контакты (+ Яндекс-карта) → Footer.
- **Навигация** (fixed сверху) прокручивает страницу к вычисленному горизонтальному
  оффсету нужной панели. На мобильном — бургер-меню.

### Живые эффекты

- **Фото выплывают:** каждое фото прикрыто rose-gold «шторкой» (`.cover`), которая
  уезжает по мере прохождения панели.
- **Соединение коллажа:** в галерее фото стартуют вразброс (сдвиг/поворот/масштаб) и
  «собираются» в ровный грид — разные фото двигаются с разной скоростью (параллакс).
- **Буквы по одной:** заголовки `.split-text` разбиваются на `<span class="char">` и
  проявляются со stagger по мере входа панели.
- **Отзывы** — отдельная горизонтальная лента с scrub-движением и лёгким авто-дрейфом
  (marquee) в покое.
- Плюс: плавающие градиентные пятна, курсор-свечение (скрыт на тач), 3D-tilt карточек
  (≤ ±12°), count-up для цифр.

## 📱 Мобильная версия и «уменьшить движение» (важный фолбэк)

Класс `js-ready` добавляется на `<html>` **только если**: есть `window.gsap` и
`ScrollTrigger`, **нет** системной настройки `prefers-reduced-motion`, и ширина экрана
**≥ 900px**. Иначе включается **обычная вертикальная раскладка** (скролл вниз):

- панели идут стопкой сверху вниз;
- **все фото полностью видны** (шторки скрыты через `html:not(.js-ready) .cover{display:none}`);
- **все буквы видны** (`html:not(.js-ready) .char{opacity:1}`);
- отзывы — горизонтальная лента со `scroll-snap` (листается пальцем);
- hero-видео всё равно автозапускается (muted, loop), но **без** scroll-скраба.

Весь GSAP-код обёрнут в `try/catch`: при любой ошибке `js-ready` снимается и сайт
откатывается к вертикальному виду — **ничего не остаётся скрытым**.

Фотографии — в **соседней папке** `ФОТООЛЯ` (на уровень выше папки сайта):

```

├── ФОТООЛЯ/            ← здесь 8 фотографий
└── mne-mojno-site/     ← сайт
    ├── index.html

    ├── START.bat
    ├── README.md
```

В коде фото подключаются по относительному пути `../ФОТООЛЯ/имя-файла.jpg`. Все 8 фото
используются: в hero (постер/фон), «О студии», галерее (все 8).

## 🔌 Работа офлайн

Через интернет подгружаются только: Яндекс-карта (iframe), Google Fonts
(Unbounded / Manrope / Playfair Display) и GSAP + ScrollTrigger (CDN). Без сети сайт
покажет весь контент — просто в вертикальном виде без scrub-анимаций и с системными
шрифтами.

## 🛠️ Технологии

- Чистый HTML5 + CSS3 (glassmorphism, CSS 3D transforms, clamp-типографика) + ванильный JS.
- GSAP 3.12.5 + ScrollTrigger через CDN — горизонтальный скролл и scrub-эффекты (необязательны).
- Никаких фреймворков и сборки — работает с `file://`.
